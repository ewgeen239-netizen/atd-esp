# AutoDoc.pl: структура сайта, поиск и безопасное тестирование

## Что известно о структуре autodoc.pl

| Что | Как выглядит |
|---|---|
| Поиск по номеру (EAN, артикул, OEM) | `https://www.autodoc.pl/search?keyword=<код>` |
| Карточка товара | `https://www.autodoc.pl/<бренд-slug>/<числовой-id>`, например `/blue-print/332773`, `/ate/954642` |
| Поля на карточке | «Numer artykułu: …», «EAN: …» под названием; в описании «Numer EAN», «Producent», «Stan»; цена в zł; наличие; блок OE-номеров (cross-reference); совместимость с авто |
| Особенности | Поле EAN иногда содержит не EAN (например `IC-G0VUGJ`) или слишком длинное значение. Парсер такие значения отбрасывает после проверки контрольной цифры и пишет причину в `notes`. |

Парсер (`backend/src/providers/autodoc-parser.js`) извлекает данные в порядке надёжности:

1. **schema.org JSON-LD** (`Product`: `name`, `sku`/`mpn`, `gtin13`, `brand`, `offers.price`, `availability`, `image`);
2. **microdata** (`itemprop=…`);
3. **подписи на польском** («Numer artykułu», «Numer EAN», «Producent», цена «… zł», «niedostępny»; блок «Numery OE» до «Pasuje do» / «Opis»);
4. **OpenGraph / `<title>` / canonical** для названия, фото и URL.

Поиск: если ответ поиска уже является карточкой (редирект по точному EAN), разбирается сразу. Иначе берётся первая ссылка вида `/<slug>/<id>`, а служебные разделы (`/czesci/…` и т.п.) пропускаются. Итого 1–2 запроса на код.

> Фикстуры в `backend/test/fixtures/` синтетические: они повторяют описанную структуру, но не являются копиями страниц. Из среды разработки autodoc.pl был недоступен, поэтому **первая проверка на живом сайте — ваш шаг** (ниже).

## Правовые и технические ограничения

- Условия использования сайта и robots.txt важнее, чем техническая возможность. Если `/search` запрещён в robots.txt, провайдер `autodoc` откажется работать при `AUTODOC_RESPECT_ROBOTS=true` (значение по умолчанию). Это сделано намеренно.
- Сайт может отвечать 403/429 или показывать антибот-страницу (Cloudflare и т.п.). Сервис распознаёт это, **сразу встаёт на паузу** (`EXTERNAL_COOLDOWN_MINUTES`) и не пытается обходить защиту.
- Scraping-API (ScraperAPI, ZenRows, Piloterr, Apify) технически решают блокировки, но юридически ничего не меняют.
- **Лучший вариант для склада AutoDoc:** попросить у IT/WMS выгрузку `EAN; артикул; бренд; название; OEM; цена` и импортировать её (`npm run import -- file.csv`, кнопка «Импорт CSV» или cron + `POST /api/products/import`). Это быстрее любого парсинга (поиск без сети) и без рисков.

## Встроенные защитные механизмы

| Механизм | Настройка | По умолчанию |
|---|---|---|
| Честный User-Agent с контактом | `AUTODOC_USER_AGENT` | `AutodocBarcodeScanner/0.1 (…)` |
| Соблюдение robots.txt (кэш 24 ч) | `AUTODOC_RESPECT_ROBOTS` | `true` |
| Не чаще 1 запроса в N мс (общая очередь для всех провайдеров) | `EXTERNAL_MIN_INTERVAL_MS` | 3000 |
| Дневной лимит | `EXTERNAL_DAILY_LIMIT` | 300 |
| Очередь, при переполнении 429 клиенту | `EXTERNAL_MAX_QUEUE` | 5 |
| Пауза после 403/429/капчи | `EXTERNAL_COOLDOWN_MINUTES` | 15 (или `Retry-After`) |
| Кэш найденного / не найденного | `CACHE_TTL_HOURS` / `CACHE_NEGATIVE_TTL_HOURS` | 168 / 24 |
| Найденное сохраняется в локальный каталог | — | всегда |
| Таймаут | `EXTERNAL_TIMEOUT_MS` | 12000 (у scraper-API ≥30000) |

Состояние видно в `GET /api/health → external` (сколько запросов использовано сегодня, есть ли пауза и почему) и в шапке приложения (жёлтая точка означает паузу).

## Пошаговое безопасное тестирование с реальным EAN

1. **Вручную.** Откройте в браузере `https://www.autodoc.pl/search?keyword=<EAN>` и убедитесь, что товар есть. Запомните ожидаемые название, артикул и цену.
2. **Настройте UA.** В `.env`: `AUTODOC_USER_AGENT=AutodocBarcodeScanner/0.1 (warehouse EAN lookup; contact: ваш@email)`.
3. **robots.txt + поиск** (2 запроса, пауза 5 с):
   ```bash
   npm run probe -- <EAN>
   ```
   Скрипт покажет, разрешён ли `/search` для вашего UA, HTTP-статус, найденные ссылки на товары и сохранит HTML в `data/probe/`.
4. **Карточка** (+1 запрос):
   ```bash
   npm run probe -- <EAN> --follow
   ```
   На выходе будет JSON с распознанными полями. Сравните его с тем, что видели в браузере.
5. **Что делать с результатом:**
   - `DISALLOWED` в robots.txt: остаётесь на локальном каталоге и ручных ссылках;
   - 403/429/капча: не повторять; при наличии согласования можно `--via=scraper`;
   - поля не распознаны: пришлите файл из `data/probe/`, парсер правится по реальному HTML (добавьте его как фикстуру в `backend/test/fixtures/` и тест).
6. **Включение в приложении** (только после пп. 1–5):
   ```env
   EXTERNAL_PROVIDERS=autodoc
   EXTERNAL_DAILY_LIMIT=100
   ```
   Перезапустите сервер, отсканируйте тот же EAN и проверьте бейдж «autodoc.pl» в карточке. Повторный скан должен показать бейдж каталога (данные уже локальные).

Не запускайте массовые прогоны по списку EAN через внешний провайдер. Для массовой загрузки есть импорт CSV.
